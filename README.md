# Tarefas IA — edição gratuita

Aplicativo estático sem API, chave, assinatura ou serviço pago. Abra index.html no navegador ou publique gratuitamente em hospedagem estática.

O planejador usa regras locais, não IA generativa. As tarefas são guardadas no armazenamento local do navegador; use Exportar para criar backups.
